C++ NETWORKED SHOOTER

Solo Project • Multiplayer Networking • C++

C++ Networked Shooter is a university networking project where I built a simple 2D multiplayer team deathmatch game using C++ and raylib.

Multiple players can connect to a server, join either the red or blue team and ready up in a multiplayer lobby before starting a match. During the game, players can move, aim and shoot while the server manages health, respawning, team scores and the match result.

MY ROLE

Solo Programmer

I built both the client and server applications and implemented the networking used to keep multiple players connected and in sync. This included handling connections, network messages, replicated gameplay, lobby systems, player state and server-side game logic.

KEY CONTRIBUTIONS

  • Client-server multiplayer architecture
  • TCP and GameNetworkingSockets communication
  • Reliable and unreliable network messaging
  • Cap'n Proto message serialisation
  • Multithreaded server networking
  • Multiplayer lobby, chat and ready system
  • Player movement and aim replication
  • Projectile and gameplay replication
  • Server-managed health, respawning and scoring
  • Connection and disconnection handling
